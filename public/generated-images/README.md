# Generated image library

This folder contains AI-generated VAW LYNE images only. Uploaded identity photos and uploaded style references are intentionally excluded.

## Sets

- `curvier-set/` — the nine-image curvier set
- `original-12/` — the completed first 12-look set
- `next-12/` — the current new set (images 01–09; add 10–12 when generated)
- `portraits/` — generated portrait crops/variants
- `sauna/` — generated sauna-themed images

`manifest.json` lists every generated image and its public path. In a deployed Vite site, paths such as `/generated-images/original-12/01-satin-bed.jpg` are served directly from this folder.
